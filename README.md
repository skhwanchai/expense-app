# จดรายจ่าย

แอปจดรายจ่ายส่วนตัว บันทึกแค่รายจ่าย ดูยอดรายวัน รายสัปดาห์ รายเดือน และสรุปเดือนแบบ Wrapped

- หน้าแอป: GitHub Pages (ไฟล์ในโฟลเดอร์นี้)
- ข้อมูล: Google Sheet ผ่าน Apps Script (API ต้องใช้รหัสลับ)
- รหัสลับไม่ได้อยู่ใน repo นี้ ใส่ครั้งเดียวในแอปบนแต่ละเครื่อง

## ใช้งาน

1. เปิดแอปบนมือถือ แล้วเพิ่มลงหน้าจอโฮม
2. ใส่รหัสลับ (ดูได้จาก Apps Script โดยรันฟังก์ชัน `showKey` แล้วเปิดบันทึกการดำเนินการ)
3. อยากเปลี่ยนรหัส ให้รัน `resetKey` แล้วใส่รหัสใหม่ในแอป (แตะแถบสถานะใต้หัวข้อ)

แดชบอร์ดอยู่แท็บแรกของ Google Sheet ถ้าแท็บหาย ให้รัน `buildDashboard` ใน Apps Script
